# 🧠 Neural Network From Scratch

A simple feedforward neural network implemented entirely from scratch using Python and NumPy.

This project demonstrates the fundamental concepts behind neural networks without using high-level deep learning frameworks such as TensorFlow or PyTorch.

## 🚀 Features

- Forward propagation
- ReLU activation
- Sigmoid activation
- Binary cross-entropy loss
- Backpropagation
- Gradient descent
- Weight and bias optimization
- XOR classification
- Training loss visualization
- Prediction system
